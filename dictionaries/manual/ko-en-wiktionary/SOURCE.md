# ko-en-wiktionary: Wiktionary Korean → English

- **Headword language:** `ko`. **Gloss language:** `en`.
- **Size:** 55552 headwords, 395791 inflected-form / alternate-spelling entries in the `.syn` index.
- **Made by:** [xxyzz/wiktionary_stardict](https://github.com/xxyzz/wiktionary_stardict), release `20261029` (2026-10-29), asset `ko-en.tar.zst`. SHA-256 of that archive: `c1d2454e7fcd5c7c11bf6dd065deaf8da089ccdf5ce08be2c668cedcdc9a8372`.
- **Data source:** English Wiktionary, snapshot 2026-10-01, via Wikimedia Enterprise / Kiwix dumps as processed by the tool above.
- **License:** **CC BY-SA 4.0**, the Wiktionary content license. The `.ifo` says so itself: `description=Snapshot 2026-10-01, Wiktionary license CC BY-SA 4.0`. Text: https://creativecommons.org/licenses/by-sa/4.0/
- **Why redistribution is permitted:** CC BY-SA allows copying and redistribution with attribution and the same license. The tool's repo is GPL-3.0-or-later, which covers its code. Its own output labels the data as CC BY-SA 4.0, and CC BY-SA 4.0 content may be used inside GPL-3.0 works, so the two do not conflict.
- **Attribution:** content from English Wiktionary (https://en.wiktionary.org) contributors, via xxyzz/wiktionary_stardict.
- **Changes made here:** none. The files are the archive's contents extracted as-is (`res/` images included).
- **Format notes:** `sametypesequence=h` (HTML entries, full Wiktionary article markup). Lichtung's parser currently over-includes pronunciation, examples and etymology as extra senses and ignores the `.syn` file; see the Lichtung issue tracker for the planned native fix.

Inflected forms resolve only through the `.syn` index (about 396k entries).
